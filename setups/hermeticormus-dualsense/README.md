# hermeticormus-dualsense

The setup hypr-gamepad was built on: [config.toml](config.toml).

- Controller: a DualSense over Bluetooth, with the udev rule installed (lights and the mic button).
- Desktop: Omarchy on Hyprland 0.56, with omaspaces' split workspaces.
- herdr with prefix-free alt chords: Alt+Left/Right tabs, Alt+Up/Down spaces, Alt+Shift+Up/Down agents.
- Talk: voice-flow; Create toggles its voice ideas listener.
- The board (PS tap), the sessions wheel (PS held), the jump list (`sun-wheel`) and the workboard windows are this desk's own tools. On another desk, drop `[jump]`, `[board]`, `[wheel]`, `[ideas]` and `[windows]`, and set `[herdr]` to your own keys.
